# Simple Dice Roller

A small 3D dice roller made with Python, pygame-ce, and PyOpenGL.

Click the window to roll. When the die stops, its result is on top. Press `Esc` or close the window to quit.

## Run

Install the packages:

```powershell
python -m pip install -r requirements.txt
```

Start the game:

```powershell
python "Simple Dice Roller.py"
```
